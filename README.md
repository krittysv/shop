# Shop App

This is a simple shop application built using Java and Gradle.

## Overview

The Shop App is a sample Java application that demonstrates basic shopping functionality such as managing products, adding items to a cart, and processing orders.

This project is intended for learning and demonstration purposes.

## Technologies

- Java
- Gradle
- JUnit 5
- Hamcrest

## Requirements

- Java 8 or later
- Gradle 7+ (or use the Gradle Wrapper if included)


## Getting Started

### Build the Project

Using the Gradle Wrapper:

./gradlew build

### Run Tests

./gradlew test

## Dependencies

The project uses:

- JUnit Jupiter 5.8.1 for unit testing
- Hamcrest 1.3 for assertions

## Build Configuration

This project uses the Java Gradle plugin.

Tests are configured to run using the JUnit Platform.
